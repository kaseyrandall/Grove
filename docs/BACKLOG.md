# Popple — Ideas & Backlog

A running list of things we've talked about but deferred. Not commitments —
just so nothing gets lost between sessions.

## Saved for later

### Journal as a memory timeline
Grow the **Journal** tab beyond aggregate stats into a real, dated feed of
catches — a keepsake diary: *"Aug 3 · caught Ember the Fox near Cedar Park 🦊."*
Leans into the cozy, sentimental feel. Could group by day/week, show the photo,
species, sparks, and location.

### Daily quests
A rotating daily goal layered on top of the streak system — e.g. *"catch a bird
today,"* *"catch something Rare this week,"* *"snap 3 friends."* Gives a reason
to open the app each day beyond the raw streak. Reward with bonus sparks.

### Achievement-unlocked toast (outside the catch flow)
Right now new achievements are celebrated on the catch screen. Add a general
in-app toast/banner so unlocks that happen elsewhere (e.g. crossing a streak
threshold) also get their moment.

## Bigger rocks (already in the README roadmap)

- **Better ID** — Core ML species model or cloud vision for true species names.
- **Social** — friends, shared sightings, leaderboards (data model is structured
  so a sync/backend layer can bolt on without a rewrite).
- **Real friend art** — replace placeholder emoji with commissioned illustrations.
- **Anti-cheat** — liveness checks (camera-only capture already blocks library
  uploads); relevant once competitive leaderboards exist.
